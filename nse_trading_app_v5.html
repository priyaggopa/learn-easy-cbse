How to get your Upstox API credentials (free, 5 min)
Step 1 — Create app
Go to developer.upstox.com → Login with your Upstox account → Create a new app → Set redirect URI to http://localhost
Step 2 — Get auth code
Open this URL in browser (replace YOUR_API_KEY):
https://api.upstox.com/v2/login/authorization/dialog?response_type=code&client_id=YOUR_API_KEY&redirect_uri=http://localhost
Login → copy the code= value from the redirect URL.
Step 3 — Paste below
Enter your API key, API secret, and the auth code below. The app will exchange it for an access token automatically and start pulling live data.
Note: Auth codes expire in a few minutes. If connection fails, repeat step 2 to get a fresh code. Access tokens are valid till midnight.
